# Arijit's Digital Canvas

Create a modern, visually striking personal portfolio website for Arijit Rout, a second-year B.Tech Computer Science and Engineering student at Lovely Professional University. Arijit is an aspiring software professional with a foundation in programming, web technologies, databases, and software engineering documentation. The website should present him as a motivated, technically capable student who is building practical projects and developing his expertise.

Overall Design Direction

Use the uploaded reference image as the primary visual inspiration. Recreate its clean editorial portfolio aesthetic rather than copying it exactly.

The design should feel:

Modern and premium

Minimal but visually bold

Professional and student-friendly

Typography-focused

Spacious, with strong visual hierarchy

Slightly editorial/magazine-inspired

Responsive across desktop, tablet, and mobile

Use a predominantly white/off-white background with black typography, subtle warm neutral tones, and restrained accent colors. Incorporate large typography, asymmetric layouts, generous whitespace, rounded image containers, and subtle hover/scroll animations.

The hero section should include a professional profile picture of Arijit prominently. Since no personal profile photo has been provided yet, use a clearly marked profile-photo placeholder that can be replaced later. Do not use the person from the reference image as Arijit's photograph.

1. Home / Hero Section

Create an impactful first screen inspired by the reference design.

Display:

Small personal branding/name: Arijit Rout

Large editorial headline such as:
“Hello, I’m Arijit.”

Strong secondary headline:
“B.Tech CSE Student & Aspiring Software Engineer”

Short introduction explaining that Arijit is a second-year Computer Science student at Lovely Professional University interested in programming, software engineering, web technologies, and practical technology projects.

Professional profile image prominently positioned in the hero area.

A compact availability/status badge such as “Open to learning & opportunities”

Primary CTA: View My Work

Secondary CTA: Get In Touch

Use oversized typography and an editorial composition similar to the reference image, with the text and profile image overlapping or interacting visually without becoming cluttered.

2. About Section

Institution: Lovely Professional University

Completed intermediate education in 2025

Currently developing skills in programming, databases, web development, and software engineering.

Present this section using a combination of large typography, short paragraphs, and small informational cards rather than a conventional long biography.

Include a small timeline showing his educational journey.

10. Visual Language

Take inspiration from the provided reference image's:

However, customize the visual identity specifically for Arijit Rout, a CSE student. Incorporate subtle technology-inspired details such as fine grid lines, small monospace labels, code-like microcopy, terminal-inspired accents, or tiny system/status indicators without turning the site into a stereotypical “developer portfolio.”

11. Animations & Interactions

Use polished but restrained animations:

Smooth page scrolling

Fade/slide-in animations as sections enter the viewport

Subtle image parallax

Project-card hover effects

Animated skill tags

Smooth navigation transitions

Button hover animations

Gentle typography movement

Animations should enhance the editorial design rather than distract from the content.

12. Responsive Design

The website must be fully responsive.

On mobile:

Stack the hero content vertically

Keep the profile picture prominent

Reduce oversized typography appropriately

Convert project cards into a single-column layout

Make navigation mobile-friendly

Preserve generous whitespace and visual hierarchy

Ensure accessibility with strong contrast, readable typography, semantic HTML, keyboard-friendly interactions, descriptive image alt text, and appropriately sized touch targets.

13. Brand Personality

The final website should communicate:

Curious • Technical • Ambitious • Clean • Modern • Student Developer • Continuous Learner

The portfolio should feel like the personal website of a promising CSE student who is actively developing practical skills—not like an established senior software engineer.

Use Arijit's real academic background and project experience accurately. Avoid fabricated achievements, employment history, client work, certifications, statistics, or professional claims.

Final Goal

Create a portfolio that immediately communicates who Arijit Rout is, what he is learning, what technologies he works with, and what he has built. The visual experience should be bold and memorable like the supplied reference while maintaining a clean, professional, authentic identity suitable for a B.Tech CSE student seeking future internships, projects, collaborations, and career opportunities.
